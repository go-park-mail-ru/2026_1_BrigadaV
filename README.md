### Правила оформления Pull Requests
  1. Ветка создается с названием `features/###`, где ### - имя выполняемой задачи.
  2. Название Pull Request'а соответствует названию задачки.
  3. Для того, чтобы залить изменения в ветку main нужен апрув от [Азамата]

### Установка и запуск проекта

#### Пошаговая инструкция
**1. Клонируйте репозиторий**
```bash
git clone https://github.com/go-park-mail-ru/2026_1_BrigadaV.git
```
**2. Установите зависимости**
```bash
go mod tidy
```
